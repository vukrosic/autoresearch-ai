# Promptfoo

来源：

- [promptfoo GitHub](https://github.com/promptfoo/promptfoo)
- [Promptfoo docs](https://www.promptfoo.dev)

## 它们做什么

Promptfoo 专注测试 prompt、model、agent 和 RAG 系统。它 CLI-first、local-first，并围绕自动化 evaluation 和 red teaming 构建。

有用特征：

- 声明式 config
- CI/CD 支持
- model comparison
- 本地/私有 evaluation
- 安全和漏洞报告

## 要学习什么

- 在用户信任系统前，evaluation 应该容易运行。
- CLI + config 是可重复检查的正确形态。
- Local-first 对信任和隐私很重要。
- 对比结果应该容易阅读，而不是藏在 notebook 里。

## AutoResearch-AI 有何不同

- AutoResearch-AI 关注自主研究循环，而不只是 prompt test。
- 它需要持久状态、run ledger 和 agent instructions。
- Prompt evaluation 应该是一个 adapter 或 subcommand，而不是整个产品。
