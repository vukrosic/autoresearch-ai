# LangSmith

来源：

- [LangSmith evaluation page](https://www.langchain.com/evaluation)
- [LangSmith evaluation concepts](https://docs.langchain.com/langsmith/evaluation-concepts?mode=ui)

## 它们做什么

LangSmith 覆盖整个生命周期的 evaluation：离线 benchmark、单元/回归测试、在线监控、启发式检查、LLM-as-judge、pairwise comparison 和人工 annotation queue。

## 要学习什么

- 把执行和 evaluation 分开。
- 同时支持自动评分和人工 review。
- 给用户一个系统化对比 variant 的方式。
- 把 evaluation 当作工作流，而不是一次性脚本。

## AutoResearch-AI 有何不同

- AutoResearch-AI 范围更窄，也更基于文件。
- 它应该能安装到任何仓库，并生成工作流骨架。
- 它可以借鉴 evaluation 想法，但不复制完整平台表面。
