## 它们做什么

OpenHands 提供更完整的 agentic development stack：SDK、CLI、本地 GUI、cloud 和 enterprise。

## 要学习什么

- 把小 CLI 和更大的托管产品分开。
- 本地 GUI 可以帮助用户 onboarding，但 CLI 是核心信任锚点。
- enterprise/cloud 层应该是附加能力，而不是第一次有用运行所必需的东西。

## AutoResearch-AI 有何不同

- AutoResearch-AI 从研究工作流文件和实验日志开始。
- 它应该更轻，并且对自主研究更有主张。
- 如果开源循环足够强，托管层可以稍后再做。
