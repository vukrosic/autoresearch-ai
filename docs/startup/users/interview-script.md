# 访谈脚本

目标：在 pitch 前先理解工作流。

## 开场

我正在构建一个开源 npm 包，它会把 autonomous research harness 安装进 AI 仓库。它面向 Codex 和 Claude Code 这类 agent，让它们可以更可靠地规划实验、运行检查并记录结果。

你能带我看一下你现在如何在一个仓库里运行实验吗？

- 你现在关注哪个仓库或研究工作流？
- 最重要的 metric 是什么？
- 你如何建立 baseline？
- 实验想法来自哪里？
- 你如何跟踪 run 和失败尝试？
- 工作流里什么最烦或最慢？
- agent 在哪里会有帮助？
- agent 在哪里会危险？
- 你会安装一个创建 prompt files、rules 和 run ledger 的 npm 包吗？
- 什么会让你信任或拒绝它？

## 结束
