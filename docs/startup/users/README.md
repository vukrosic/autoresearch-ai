# 用户和客户发现

这个文件夹跟踪可能使用 AutoResearch-AI 的人。

目标不是过早销售。目标是学习真实研究人员如何运行实验，以及 agent harness 在哪里节省时间。

## 用户分层

- 博士生
- AI 研究实验室
- 独立研究员
- 优化 prompt、agent、eval、model 或 fine-tune 的公司

## 每周目标

- 向潜在用户发送 3 条短消息
- 每两周进行 1 次更深入对话或 repo walkthrough
- 每周写 1 条学习笔记

## 应该请求什么

请求一次 repo walkthrough，而不是泛泛意见。

有用的请求：

`Can I watch how you currently plan, run, and track experiments in one repo? I am building an open source npm harness that helps Codex/Claude run disciplined research loops.`
