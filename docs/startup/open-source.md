# 开源计划

AutoResearch-AI 应该开源，因为研究工作流需要信任。

用户应该能够检查：

- prompts
- agent rules
- adapters
- repo detection
- run ledger schema
- experiment templates
- report generation

## 仓库目标

公开仓库应该保持简单：

```text
autoresearch/
  bin/
  templates/
  docs/
  examples/
  package.json
  README.md
  ROADMAP.md
  CONTRIBUTING.md
  LICENSE
```

## 保持开放的内容

- npm CLI
- harness generator
- agent prompts
- repo adapters
- local run ledger
- local reports
- examples and templates

## 以后可能付费的内容

- hosted dashboard
- team collaboration
- private run history
- managed GPU queue
- enterprise integrations
- priority support
- lab-specific templates
- private eval and compliance workflows

## 边界

开源项目本身应该有用。付费功能应该增加便利性、规模化和协作，而不是锁住核心研究循环。
