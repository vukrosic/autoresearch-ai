# 定位

短版：

AutoResearch-AI 把代码 agent 变成有纪律的自主研究循环。

长版：

AutoResearch-AI 是一个开源 npm 包，会把研究规则、prompt、adapter、scratchpad 和实验日志安装进 AI 仓库。之后 Codex、Claude Code、Hermes、Cursor 或其他 agent 就能带着更清晰的目标、更好的记忆和可复现证据运行实验。

## 这样说

- 自主 AI 研究 harness。
- 用于 agent-run 实验的开源 npm 包。
- 面向 ML 仓库的 baseline-first 实验循环。
- 给 Codex 和 Claude Code 使用的 prompt、workflow 和 run ledger。

## 不要过度承诺

- 不是神奇的模型 optimizer。
- 不是 PhD 级判断的替代品。
- 不保证改进每个模型。
- 不限于 NVIDIA。

## 第一个承诺

安装 AutoResearch-AI，把生成的 prompt 粘贴给你的 agent，得到一个包含目标、计划、想法、run 和报告的干净研究循环。
